## 💡 Example

### Even or Odd

```c
#include <stdio.h>

int main() {
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    if (n % 2 == 0)
        printf("Even");
    else
        printf("Odd");

    return 0;
}
```

### Output

```text
Enter a number: 10
Even
```
